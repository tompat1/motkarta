# Motkarta agent entry point

Before doing any work in this repository, read and follow
[`.agents/AGENTS.md`](.agents/AGENTS.md). It contains the repository architecture,
operating principles and mandatory directive routing.

For any work involving machine learning, scoring, recommendation ranking,
personalization, discovery, hidden-gem logic, residual/underexposure research,
anomaly detection, recommendation telemetry, evaluation, experiments or drift:

1. Read [`directives/ml_recommendation_system.md`](directives/ml_recommendation_system.md).
2. Follow the canonical documentation beginning at
   [`docs/ml/README.md`](docs/ml/README.md).
3. Preserve the documented data boundaries and safety invariants.
4. Update tests and the affected ML documentation with every behavior change.

For Specialty Coffee work, also read
[`directives/specialty_coffee_gold_standard.md`](directives/specialty_coffee_gold_standard.md).
